Can the personal-use installation cross every lifecycle boundary cleanly?

This demo turns the installation decision into observable gates: an ad-hoc-signed app-bundled service, a dedicated unprivileged account, loopback-only standard macOS printing, transactional tagged-source upgrades, bounded local diagnostics, complete removal, and clean reinstall.

Clicks are not platform or hardware evidence. Press an observation only after performing it on the reference Mac. This file records the state in memory so the human driving the experiment can spot illegal transitions and decide whether the selected lifecycle survives. It never installs, removes, signs, or elevates anything itself.
