Throwaway logic prototype

Can the selected architecture carry one ordinary macOS print job all the way to paper?

This demo makes the proof contract tangible: drive the Printer Application, firmware, USB, raster, and recovery states in the same order the reference Mac must observe them. The available UGREEN dock is the validated reference path; the direct adapter remains an explicit pre-release validation gap because that hardware is unavailable.

Clicks are not hardware evidence. Record an action here only after observing it on the reference Mac and printer. The initial state reflects the completed 24 August 2026 dock-path probe: an ordinary macOS job, unprivileged firmware bootstrap and USB transport, corrected 600 dpi raster mapping, and clean full-page A4 output all passed. The direct-adapter path remains unobserved.
